# Customer Support SLA & Workforce Performance Analytics

An end-to-end data analytics and business intelligence project designed to evaluate customer support operations, SLA compliance, workforce productivity, and customer satisfaction.

## Project Overview

This project focuses on analyzing customer support ticket data to identify operational inefficiencies, monitor service-level agreements (SLAs), and generate actionable insights for improving support team performance.

## Objectives

- Analyze customer support ticket trends.
- Monitor SLA compliance and breach rates.
- Evaluate ticket resolution and response times.
- Measure support agent productivity.
- Identify workload distribution and operational bottlenecks.
- Analyze customer satisfaction and service quality.

## Technology Stack

- Python – Pandas, NumPy, Matplotlib, Seaborn
- SQL – Joins, CTEs, aggregations, window functions
- Excel – Pivot tables and KPI reporting
- Power BI – Interactive dashboards and DAX

## Planned Modules
